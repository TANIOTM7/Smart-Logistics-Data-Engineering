This folder contains the PySpark notebook used in the Smart Logistics Data Engineering project.

## Notebook

**Smart_Logistics_Silver_Gold_GitHub.ipynb**

The notebook covers:

- Reading raw logistics CSV data from Microsoft Fabric Lakehouse.
- Data exploration and schema inspection.
- Data cleaning and transformation.
- Silver layer creation and data quality validation.
- Gold layer aggregation and performance analysis.

## Technologies

- Microsoft Fabric
- PySpark
- Python
- Delta Lake
