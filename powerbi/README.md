
# Power BI Dashboard

This folder contains the Power BI report for the Smart Logistics project.

## Report

**Smart_Logistics_Analytics.pbix**

The dashboard provides insights into:

- Total logistics events.
- Overall on-time performance.
- Average delivery delay.
- Average detention time.
- Facility-wise performance.
- City-wise performance.
- Pickup versus delivery performance.

## Technology

Microsoft Power BI
